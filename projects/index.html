Projects

Blockography.AI

A machine learning project for the ACM AI Competition focused on image classification using handcrafted visual features and a Random Forest classifier.

  • Extracted HSV color statistics, BGR histograms, texture features, entropy, and vegetation ratios.
  • Used RandomizedSearchCV and 3-fold cross-validation for model tuning.
  • Finished in the top 30% of 50 participants.

Baymaxxing

An AI-driven mental health web application that analyzes user input and provides context-aware responses.

  • Built with Python, Flask, and NLP techniques.
  • Collected and processed Reddit data using the PRAW API.
  • Integrated generative AI models for contextual responses.
  • Created a Tableau dashboard to visualize sentiment and severity trends.
